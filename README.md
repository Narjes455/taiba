# ذاكرة طيبة

ذكريات كتبها أهل المدينة المنورة عن مدينتهم، أعدتُ إحياءها بالصورة.

**الموقع:** https://narjes455.github.io/taiba/

تسع ذكريات منشورة لأربعة كتّاب، لكل ذكرى صورة مولّدة بالذكاء الاصطناعي تبدأ باهتة كصورة قديمة، وتعود إليها الألوان كلما مرّرت إليها.

## كيف صُنعت
- **جمعت** ذكريات منشورة لكتّاب من أهل المدينة.
- **أحييت** كل ذكرى بصورة مولّدة بالذكاء الاصطناعي.
- **صممت** التجربة وبرمجتها بـ HTML وCSS وJavaScript، بدون أي مكتبات.

الذكريات لأصحابها، ومكتوبة في الموقع بتصرف، والأسطر بين علامتي التنصيص من مقالاتهم بنصها. الصور تخيّل للذكرى وليست صوراً حقيقية.
